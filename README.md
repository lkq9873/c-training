# C言語 発展編 研修 — 課題プログラム

社内研修「C言語 発展編」の課題 3〜16 で作成した C プログラムとフロー図です。

環境は UNIX (Linux)、システムコールを使った **ファイル操作 / プロセス / プロセス間通信** が主なテーマです。

## ビルド

C90 準拠を確認するため、以下のオプションでコンパイルします。

```bash
cd c-advanced
gcc -Wall -std=c90 -pedantic-errors -I../include -o task13 task13.c
```

| オプション | 意味 |
| --- | --- |
| `-Wall` | すべての警告を有効にする |
| `-std=c90` | C90 を指定する |
| `-pedantic-errors` | ISO C に準拠しないコードをエラーにする |

全ファイル警告ゼロでコンパイルできることを確認済みです。

## 実行方法（2 プログラム構成のもの）

いずれも **受信側 / サーバー側を先に起動**します。先に起動した側は相手が接続するまでブロックします。

```bash
# 課題14
./task14_receive &   # 先
sleep 1
./task14_send        # 後

# 課題15 / 課題16
./task15_server &    # 先
sleep 1
./task15_client      # 後
```

## 方針メモ

各ソースの先頭に「設計方針」コメントブロックがあり、以下を明記しています。

- **エラー発生時に打ち切るか継続するか** — 前提が成立せず続行できない場合は打ち切り、続行可能な場合は継続する
- **文字列の終端** — 送信側が終端のヌル文字を含めて送信し、受信側が最終バイトを確認する

`c-advanced/summary_zh.md` に、学習内容と各課題の考え方を中国語でまとめています。
